# Moduli italiani per Mangayomi

Sorgenti anime in italiano per l'app [Mangayomi](https://github.com/kodjodevf/mangayomi) (iOS / Android / desktop).

## Come aggiungerle

In Mangayomi: **Impostazioni → Browse → repository anime**, incolla:

```
https://raw.githubusercontent.com/adam72881/it-ext-repo/mangayomi/anime_index.json
```

Poi in **Browse** installa le sorgenti che vuoi.

## Sorgenti

| Sorgente | Sito | Contenuto |
|---|---|---|
| **AnimeWorld** | animeworld.ac | Anime (sub/dub ITA) |
| **HentaiWorld** | hentaiworld.me | Hentai (18+) |

Se un sito cambia dominio, aprila nelle impostazioni della sorgente e aggiorna il campo **Dominio**.
